### 响度与真峰值合同

- 每个交付 OGG 的离线母带目标为 `-20 LUFS` integrated，自动合同的单轨真峰值上限为 `<= -2.0dBTP`。当前十二首实测均更低，最高（最接近 `0`）为 `-2.24dBTP`。这些值由与交付 SHA-256 绑定的离线测量产生，浏览器运行时不负责猜测或重新分析母带。
- 同境两首使用同一呈现增益，避免章节切换造成无叙事依据的响度跳变：晨岛 `-2dB`、云野 `-1dB`、雨林 `-2dB`、霞谷 `0dB`、禁阁 `-3dB`、伊甸 `-1dB`。
- 在不计用户音量、淡化包络和其他声层时，单 deck 的名义呈现响度依次为 `-22 / -21 / -22 / -20 / -23 / -21 LUFS`。由 `-2.0dBTP` 自动合同和境界增益推导的单 deck 真峰值上限依次为 `-4 / -3 / -4 / -2 / -5 / -3dBTP`；逐曲当前实测值见完整性台账。
- 上述真峰值上限约束单首母带和单 deck 呈现。双 deck 等功率淡化另以最坏 `+3dB` 余量验证，叠加后仍须 `<= -1dBTP`；这项技术检查不等于天气、效果、推进声加入后的整机总线签收，更不等于玩家听感签收。

## English

This directory contains only `21` audio files with runtime consumers: two local instrumental/no-lyric scores for each of six realms (`12` total), plus `9` CC0 event samples decoded by Web Audio. All scores ship as Ogg Vorbis. The project uses the CC0 option for `10` scores and CC-BY 3.0 for `2`. Legacy `spaceEngine_002.ogg` had no runtime consumer, while legacy `thrusterFire_002.ogg` also clipped; both were removed from delivery on `2026-07-26`.

> Automated validation is a technical release gate, not player listening sign-off. It can verify files, license metadata, hashes, durations, offline loudness, true peak, playlist grouping, and rhythm-packet consistency. It cannot decide whether the music feels natural inside the actual maps, weather, flight layers, or target speakers. “Automation passed” must never be reported as “players approved the mix.”

### Loudness and true-peak contract

- Every delivered OGG has an offline mastering target of `-20 LUFS` integrated and an automated per-track true-peak ceiling of `<= -2.0dBTP`. All twelve current measurements are lower, with `-2.24dBTP` the highest value closest to zero. Measurements are hash-bound offline evidence; the browser does not guess or re-analyze mastering.
- Both scores in a realm share one presentation gain: Dawn `-2dB`, Prairie `-1dB`, Rainforest `-2dB`, Valley `0dB`, Vault `-3dB`, and Eden `-1dB`.
- Before user volume, fade envelopes, and other audio layers, nominal per-deck presentation loudness is `-22 / -21 / -22 / -20 / -23 / -21 LUFS`. The automated `-2.0dBTP` asset ceiling plus realm gains yields per-deck ceilings of `-4 / -3 / -4 / -2 / -5 / -3dBTP`; current per-score measurements are recorded in the integrity ledger.
- These peak ceilings govern individual masters and single-deck presentation. Equal-power two-deck overlap has a separate worst-case `+3dB` reserve check and must remain `<= -1dBTP`. That technical check is neither whole-bus approval after weather, effects, and propulsion nor player listening sign-off.

### Nine event samples and synthesis

The nine event samples come from the linked Kenney CC0 packs: [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) supplies `impactMetal_003.ogg`; [Digital Audio](https://kenney.nl/assets/digital-audio) supplies pickup, active-takeoff, navigation/start, acceleration, braking, and game-over samples; [UI Audio](https://kenney.nl/assets/ui-audio) supplies generic UI and system-toggle samples.

`phaseJump3.ogg` serves only an active SPACE launch from manual, touch, or autopilot obstacle intent; passive `jump-platform-release` separation at a physical platform lip never requests it. A decoded sample is not doubled with a bright synthesized accent. Restrained full synthesis is used only when a sample is missing or undecodable. Left/right steering, autopilot on/off, and near/mid/far thunder have dedicated synthesis. Rain, wind/snow, hail, dust, propulsion, braking, and water/snow contact use persistent filtered layers and require no additional files; rain continuously crossfades programmatic light, steady, and downpour layers rather than relying on an absent recording asset.

`V23-effect-assets-1` is generated from the unchanged bytes of these nine OGG files by `tools/generate-effect-audio-inline.mjs`. `file://` decodes inline directly; release-keyed HTTP(S) requests use the same bytes after transport failure or an undecodable successful response. Both enter the same Web Audio decode, gain, rate, and bus.
