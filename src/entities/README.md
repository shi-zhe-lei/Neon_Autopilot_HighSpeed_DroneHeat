# Entities / 实体

## 中文

环境烛群在预热时按各自缩放后的真实 `boundingBox` 装配：烛台底面落在作者布局高度，火焰底面与该烛台顶面相接，接缝目标为 `0m`。随机烛台高度与火焰尺度继续独立变化，随机数消费顺序不变；不能使用未缩放的半高推算中心。world 仍独占逐实例地形采样与接地重绑，保留原有 `[-0.016m, 0.032m]` 接缝校验和 `0.001m` 容差。这个装配修复避免特定种子在启动阶段触发接缝越界，不改变家族数量、实例批次、材质、局部灯或拾取/碰撞合同。

保存飞船视觉、损伤形态和推进表现。固定碰撞代理与玩法状态由既有合同约束，视觉改动不得扩大它们。

`SURFACE_FOOTPRINT_CONTRACT` 是飞船与积水、积雪交互的唯一局部坐标合同。它深度冻结固定碰撞半尺寸、`-Z` 前向、船腹压力中心及左右尾部下洗点；压力扫掠半宽/半长直接派生自 `hx=0.72m`、`hz=1.36m`，侧推进舱下洗点固定为 `x=±0.62m, z=0.96m`。`createShip()` 只复制合同中的碰撞尺寸，因此运行时对象可独立使用，但不会与地表变形范围发生尺寸漂移。

`COVERED_CLEARANCE_CONTRACT` 单独保护隧道和桥下的完整健康主视觉。它冻结 `2.62m` 半翼展、`1.77m` 静态顶高及受限滚转/俯仰后的 `2.70m` 保守顶棚包络；该包络只约束覆顶路线中的视觉姿态和顶棚接触，不扩大固定障碍碰撞盒，也不改变伤害判定。

`SKY_CAPE_ART_CONTRACT` 第 2 版把飞船定义为“光之旅人 × 披风遥鲲 × 古代光器”，依据 [Sky 官方介绍](https://thatgamecompany.com/sky-children-of-the-light-out-on-google-play-now/)中的光、披风、星座与烛火母题，以及[官方概念设计](https://www.thatskygame.com/news/a-spotlight-on-season-of-performance-concept-art/)中的动物主题、朱红配色和手工大针脚语言。健康态保持 `5.24m` 对称翼展，每翼明确为五瓣、三道宽褶、两层有真实空气间隙的封闭织物，中央面具保留两枚无局部灯的光眼；至少 `70%` 表面保持安静，现代装甲面板和可见涡轮数量均为 `0`。暖象牙陶石、哑光朱红织物和克制旧金取代亮黑座舱与铬面机械堆叠；全部推进、成长变色、损伤三形态、护盾、俯视环和四条灵光尾带仍完整保留。

`SHIP_COMPONENT_CLEARANCE_CONTRACT` 冻结模型内部装配净空：披风根在 `|x|=0.80m`，静态离固定侧舱外缘 `0.04m`，最大呼吸内移后仍保留至少 `0.022m`；外披风顶面与织物内层底面相隔 `0.045m`；围巾内缘离主光孔至少 `0.26m`。主焰、双侧焰和双反推焰分别固定在 `z=1.20 / 1.12 / 0.78m` 的喷口根平面，所有焰体几何从局部轴 `0` 只向喷口外延长，因此怠速、满推、差动转向和制动缩放都不会把根部拉进船壳或让火焰悬空。该合同只约束视觉装配，不改变固定碰撞、地表下洗或物理。

High 可逆细化船壳、玻璃、披风翼与旧金 PBR，但仍保持高粗糙、低金属的手工材质，只把显式推进光、烛芯、眼睛和警示节点加入 Bloom Layer 12，并使用黑色渐变接地阴影。局部灯数量固定为 `0`，因此不会产生跟随飞船的道路亮斑。

`setTunnelBounce(probe)` 复用一份稳定的线性 RGB uniform，让船壳、腹壳、饰边、披风与衬片接收真实隧道的间接漫反射。运行时传入导航作者灯光 profile 的 `{ valid, enclosure, irradiance, red, green, blue }`；`irradiance` 只含连续底光乘洞口遮蔽，不能传入灯站峰值或动态灯强度，也不能在船端再次乘 `enclosure`。标准 PBR 在 `lights_fragment_maps` 之后、漫反射积分之前单次应用 `PI / 0.18 × 0.72` 接收校准，保留原有程序纹理、粗糙度、色彩、伤害色与自发光。实体材质及其克隆共享同一 uniform，Low / Medium / High 切换不重建材质；玻璃与显式发光效果不参与。离开隧道、无效探针和销毁立即归零。该路径不增加灯、网格、纹理或绘制次数，High 灯池继续独占灯下直接照明与高光；只读质量诊断公开探针有效性、遮蔽、照度和接收增益。

俯视构图把可视飞船的合成巡航与基础悬浮缩放到 `30%`，以保留机体辨识度并消除战术视角里的多余晃动。该缩放只作用于运行时呈现，不改动飞船几何、碰撞代理、压力足迹、路线位置或玩法物理。

`updatePropulsionFeedback()` 只消费运行时发布的 `coreSpool`、`coreRpm`、`thrustNormalized`、`steeringActuator` 与已解析的挡位负载包。主焰、内焰与侧焰以 `max(thrustNormalized, energizedSpool)` 形成 `exhaustEnergyNormalized`：松油门当帧实际推力仍归到踏板/怠速的真实值，但余热尾焰继续跟随权威核心以 `1.8s⁻¹` 自然衰减，不会瞬间缩回待机形态，也不引入第二套油门计时器。满推端点与原几何一致，挡位负载仍削弱可见能量并施加有界低频喘振。速度只控制外围光流；本模块不读按键、不从速度反推动力，也不回写物理。左右侧焰围绕同一实际前向推力做 `±18%` 对称差动，因此平均物理推力保持不变；反推焰继续使用独立短保持包络。冷启动、`frozen` 和 `resetPropulsionFeedback()` 都与 HUD、音频共享 `1,800 RPM` 怠速，暂停冻结完整上一帧。

速度呈现与新的真实道路尺度一致：外围光流在 `70km/h` 前保持关闭，P 自动巡航 `120km/h` 时清晰可读，并在普通2挡的 `160km/h` 包络达到完整强度；高速道路与跳台3挡继续增加真实前向速度，但不会再放大光流或巡航晃动。开放道路的细微巡航姿态从 `20km/h` 渐入，以 `120km/h` 为基线、`160km/h` 为满量程；`0km/h` 不产生光流或巡航晃动。`SHIP_HEAT_PRESENTATION_CONTRACT` 只读记录 `1挡≈110km/h / P巡航120km/h / 2挡≈160km/h / 高性能3挡≈280km/h`，并把热色曲线固定为 `80km/h` 起点、`160km/h` 中段、`280km/h` 满量程。日常一挡仅有细微热色，P 的普通巡航通常停留2挡；MT 可手动选择3挡，AT 在无目标上限满油门下也可自动升入3挡，因此最亮高温属于真实3挡速度而非某种变速箱模式。终端亮色由同一已平滑热量的平方派生，不再保留隐藏或不可达的第二阈值。光流位移仍按显示速度除以 `3.6` 得到真实米每秒，不伪造额外速度。

`updateShipLifeForm()` 只读共享成长档的 `state.handling.colorProgress`，让船壳、披风、引擎与光效随烛光数量沿暖金 → 紫 → 青连续变色；危急红色仍是最终安全提示。原有 `60Hz` 下 `0.08–0.10` 的材质响应会按传入 `dt` 换算为等墙钟时间混合，因此 `30 / 60 / 120Hz` 的一秒颜色过渡一致。该颜色进度只改变呈现，不写入推进、速度、碰撞、路线或玩法随机数。

普通损伤后的 `INVULNERABILITY_SHIELD_PRESENTATION_CONTRACT` 只读取运行时同一份 `1.32s` 权威无敌剩余时间。`dawn-starward` 由一个中央透明、FrontSide、雾适配且不进入 Bloom 的外壳，三条带后方断口的青/金/紫星轨，以及一次绘制的五个实例锚点组成；Low / Medium / High 最多显示 `1 / 2 / 3` 条星轨和 `1 / 3 / 5` 个锚点。外壳通过 `THREE.UniformsUtils.merge()` 克隆标准雾参数，保证 Three.js 在第一次显示时刷新 `fogColor / fogDensity / fogNear / fogFar` 不会访问缺失记录。`prepareInvulnerabilityShieldCompilation()` 只为启动编译暂时公开零透明度结界，调用方必须在 `finally` 中恢复隐藏基线。受击形成缩放只持续 `0.18s`，最后 `0.34s` 连续收束并在归零时隐藏；车头视角关闭全部世界罩，俯视隐藏星轨/锚点并复用 `topViewHalo`。减少动态时所有空间变换静止，暂停冻结内部星流相位。飞船主视觉始终常显；该层不能延长计时、决定损伤、扣血、发事件、播放音效或写回伤害锁。

`candlelight.js` 冻结六境 `12` 个可收集烛光家族与 `6` 个环境烛群家族。`CANDLELIGHT_ART_CONTRACT` v2 把两类不透明烛器统一为 `metalness=0` 的哑光石质/陶质自然介电表面；透明火焰、光环和尾迹继续独立取得自发光与 Bloom，可收集光环仍只是无碰撞世界空间可读提示，不是拾取范围。可收集物始终服从运行时既有 `0.62m` 半尺寸、`0.88m` 交换区净空、唯一奖励和碰撞时序；以可达 `45m/s` 道路包络审计时，其可读距离仍由 `180m` 下限主导，不再保留旧的 `300m/s` 展示标尺。环境烛群仅可放在 `roadside / terrain`，保持无拾取、无碰撞、无地图权威。两类均不创建 `THREE.Light`，现代机械零件和霓虹灯具数量固定为 `0`。工厂必须在玩法开始前预热，复用时完整复位姿态、材质、透明度、发光和分类元数据，帧内不得补建几何或材质。共享几何以 `neonV23ImmutableTopology` 标记不可变拓扑，使 `modelDebug` 对同一拓扑只审计一次；该标记不得合并各池根独立的材质、姿态或分类状态。

`obstacles.js` 第 3 版让六境全部 `30` 个障碍家族拥有真实不同的封闭造型：晨岛使用风翼与日孔，云野使用钟花与蝶瓣，雨林使用根拱与雨滴，霞谷使用冰扇与织风旗，禁阁使用书页与星环，伊甸使用裂石与余烬冠。每族的阻挡核心、浅浮雕与无碰撞提示都有独立实测几何哈希；提示已改为封闭薄记忆花瓣或断续节奏的星纹丝环，不再复用同一个圆环。阻挡体坚持 `metalness=0`、`roughness>=0.84` 的自然介电哑光表面，提示使用没有金属通道的透明自发光材质，局部灯、现代机械零件与霓虹灯具数量均为 `0`。生产分类固定包含 `butterfly-petal-guardian / pilgrim-terrace-pier / gliding-ice-veil / orbiting-memory-ribbon / circling-constellation-arch / ascending-memory-archive / ash-storm-veil`；对应动态提示语义使用 `ice-veil-glide-cue / memory-ribbon-orbit-cue / constellation-arch-circle-cue / memory-archive-rise-cue / ash-veil-sweep-cue`，运动曲线与时序不变。`static / laneChange / sweeper` 的玩法运动仍与视觉运动分类分开。运行时只传入既有 collider half；工厂把两层不透明封闭几何拟合并限制在该 AABB 内，越界装饰必须透明、深度测试、无碰撞且不投实体阴影，并由运行时单独加入 High selective Bloom。距离门以 `45m/s` 为可达参考，积分预读和视觉可读下限分别保持 `180m / 240m`。公共根节点只允许平移，路线偏航、旋转、脉冲和缩放只能发生在工厂拥有的无碰撞效果子层。`availableCount(familyId)` 只读公开已预热家族当前可立即取得的根数量，使运行时能在基础、岔路副本与对向预览同步发布前检查整组容量；它不预留、不分配，也不削弱 `acquire()` 对直接误用的耗尽错误。降低动态只冻结装饰，不得停止运行时的横向或纵向障碍运动。

`PROPULSION_LUGGING_PRESENTATION_CONTRACT` 让尾焰读取运行时同一份 `gearTorqueAvailability / gearLuggingSeverity / gearLoadNormalized`。只有踩油门形成的真实负载才会让能量 spool 最多衰减 `65%`、尾焰平均长度最多缩短 `42%`、透明度最多降低 `52%`；仅有高挡警告或松油门滑行不会制造喘振。普通动态模式复用现有焰体，以约 `1.35Hz` 的有界 `0.86–0.94` 尺度表现低频不稳，降低动态则保留静态衰减并移除周期变化。该合同不创建对象，不改变推力、速度、碰撞或相机。

## English

Ambient clusters are assembled during prewarm from each independently scaled geometry bounding box: the base bottom meets its authored layout height, and the flame bottom meets that base top with a target seam of `0m`. Random base heights and flame scales retain their original sampling order; unscaled half-heights must not determine their centers. World still owns per-instance terrain sampling and grounding, retaining the existing `[-0.016m, 0.032m]` seam check and `0.001m` tolerance. This prevents seed-dependent startup seam failures without changing family counts, instanced batches, materials, local lights, or pickup/collision contracts.

Owns ship visuals, damage forms, and propulsion presentation. Existing contracts fix the collision proxy and gameplay state; visual changes cannot enlarge them.

`PROPULSION_LUGGING_PRESENTATION_CONTRACT` makes exhaust consume runtime's shared `gearTorqueAvailability / gearLuggingSeverity / gearLoadNormalized` packet. Only genuine throttle-gated load can reduce energized spool by up to `65%`, shorten mean plume length by up to `42%`, and lower plume opacity by up to `52%`; a warning-only tall gear or throttle-off coast cannot manufacture flutter. Normal motion reuses the existing plumes for a bounded roughly `1.35Hz`, `0.86–0.94` low-frequency surge, while Reduced Motion keeps the static attenuation and removes the periodic change. The contract allocates no objects and changes neither thrust, speed, collision, nor camera.

`SURFACE_FOOTPRINT_CONTRACT` is the sole ship-local authority for puddle and snow interaction. It deeply freezes the fixed collider halves, `-Z` forward axis, belly-pressure center, and mirrored tail-downwash points. Pressure sweep half-width/half-length derive directly from `hx=0.72m` and `hz=1.36m`; the side-pod downwash anchors stay at `x=±0.62m, z=0.96m`. `createShip()` copies the collider dimensions so its runtime object remains independently usable without drifting from the surface-deformation footprint.

`COVERED_CLEARANCE_CONTRACT` separately protects the complete healthy main visual below tunnel and bridge ceilings. It freezes the `2.62m` half-span, `1.77m` static top, and a conservative `2.70m` top envelope after bounded roll and pitch. This envelope constrains only covered-route visual attitude and ceiling contact; it neither enlarges the fixed hazard collider nor changes damage authority.

`SKY_CAPE_ART_CONTRACT` v2 defines the craft as a light pilgrim, living manta cape, and ancient light reliquary. It follows the light, cape, constellation, and candle motifs in [Sky's official introduction](https://thatgamecompany.com/sky-children-of-the-light-out-on-google-play-now/) and the animal, scarlet, and large-hand-stitch language in its [official concept-art notes](https://www.thatskygame.com/news/a-spotlight-on-season-of-performance-concept-art/). The healthy form retains a mirrored `5.24m` span; each wing has five lobes, three broad pleats, and two closed cloth layers separated by real air. Its small mask has two emissive eyes but no local light. At least `70%` of the surface remains quiet, with `0` modern armour panels and `0` visible turbines. Warm ivory ceramic-stone, matte vermilion cloth, and restrained aged gold replace glossy black canopy and chrome machinery, while propulsion, growth colour, all three damage forms, shield, top halo, and four spirit wakes remain complete.

`SHIP_COMPONENT_CLEARANCE_CONTRACT` freezes internal assembly space. Cape roots begin at `|x|=0.80m`, `0.04m` beyond the fixed side pods at rest and still at least `0.022m` clear after maximum inward breathing; outer-cape top and woven-inset bottom retain a `0.045m` air gap; scarf inner edges stay at least `0.26m` outside the main light aperture. Main, side, and reverse plumes use fixed root planes at `z=1.20 / 1.12 / 0.78m`. Every plume geometry begins at local axis `0` and extends only away from its aperture, so idle, full thrust, differential steering, and braking cannot drag a root through the shell or leave it floating. This is a visual assembly contract and changes neither collision, surface downwash, nor physics.

High reversibly refines hull, glass, cape-wing, and aged-gold PBR while preserving the handcrafted high-roughness/low-metal look. Only explicit propulsion, candle, eye, and warning emitters enter Bloom Layer 12, alongside a black gradient contact shadow. Local-light count stays fixed at `0`, preventing any player-following road hotspot.

`setTunnelBounce(probe)` reuses one stable linear RGB uniform so hull, belly, trim, cape, and inset receive indirect diffuse light from the actual tunnel. Runtime supplies the navigation-authored lighting profile as `{ valid, enclosure, irradiance, red, green, blue }`; `irradiance` contains only the continuous diffuse floor multiplied by portal enclosure, never fixture peaks or dynamic-light power, and the ship must not multiply enclosure again. Standard PBR applies the `PI / 0.18 × 0.72` receiver calibration once after `lights_fragment_maps` and before diffuse integration, preserving procedural patterns, roughness, colour, damage cues, and emission. Opaque materials and their clones share the uniform through Low / Medium / High switches without material reconstruction; glass and explicit emitters are excluded. Leaving a tunnel, invalid probes, and disposal reset it to zero. This adds no lights, meshes, textures, or draws; the High pool retains direct fixture lighting and highlights. Read-only quality diagnostics expose probe validity, enclosure, irradiance, and receiver gain.

Top framing scales visible-ship synthetic cruise and base hover to `30%`, preserving craft legibility while removing unnecessary motion from the tactical view. This presentation-only scale changes neither ship geometry, collision proxy, pressure footprint, route position, nor gameplay physics.

`updatePropulsionFeedback()` consumes only runtime-published `coreSpool`, `coreRpm`, `thrustNormalized`, `steeringActuator`, and the resolved gear-load packet. Main, inner, and side exhaust derive `exhaustEnergyNormalized` as `max(thrustNormalized, energizedSpool)`: actual thrust still falls to the true pedal/idle value on release, while the hot plume follows authoritative core rotation down at `1.8s⁻¹` instead of snapping to its idle shape. This adds no second throttle timer. Full-power endpoints remain unchanged, and gear load still attenuates visible energy with bounded low-frequency flutter. Speed controls peripheral optic flow only; this module reads no keys, infers no power from speed, and cannot write physics. Side plumes retain a symmetric `±18%` differential around actual forward thrust, preserving the physical mean. Reverse flares keep their independent short hold envelope. Cold start, `frozen`, and `resetPropulsionFeedback()` share the HUD/audio `1,800 RPM` idle, while pause preserves the complete previous frame.

Speed presentation follows the new physical road scale. Peripheral optic flow stays off below `70km/h`, is clearly readable at P's `120km/h` automatic cruise, and reaches full strength at the ordinary Gear 2 envelope of `160km/h`; the high-performance road/ramp Gear 3 continues adding real forward speed without further amplifying optic flow or cruise motion. Subtle open-road cruise attitude fades in from `20km/h`, uses `120km/h` as its baseline, and reaches full range at `160km/h`; `0km/h` produces neither streaks nor synthetic cruise motion. `SHIP_HEAT_PRESENTATION_CONTRACT` read-only records `first gear ≈110km/h / P cruise 120km/h / second gear ≈160km/h / high-performance third gear ≈280km/h`, with a heat curve fixed at an `80km/h` start, `160km/h` midpoint, and `280km/h` full response. Daily first gear therefore receives only a subtle tint and P's ordinary cruise normally remains in Gear 2. MT may select Gear 3 manually, while AT may select it under uncapped full throttle, so the brightest heat belongs to real Gear-3 speed rather than one transmission mode. The terminal highlight squares the same smoothed heat instead of adding a hidden or unreachable second threshold. Streak travel still divides displayed speed by `3.6` to obtain real metres per second and never invents extra velocity.

`updateShipLifeForm()` reads only the shared growth profile's `state.handling.colorProgress`, continuously shifting hull, cape, engine, and glow from warm gold → violet → cyan as candlelight accumulates; critical red remains the final safety cue. The authored `0.08–0.10` material response at `60Hz` is converted through the supplied `dt`, giving `30 / 60 / 120Hz` the same one-second color transition. This color progress is presentation-only and writes neither propulsion, speed, collision, routing, nor gameplay RNG.

`INVULNERABILITY_SHIELD_PRESENTATION_CONTRACT` reads only runtime's authoritative `1.32s` invulnerability remainder. The `dawn-starward` ward combines one centre-clear FrontSide fog-aware shell excluded from Bloom, three rear-gapped cyan/gold/violet star orbits, and five instanced anchors in one draw; Low / Medium / High show at most `1 / 2 / 3` orbits and `1 / 3 / 5` anchors.
