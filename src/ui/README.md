# UI helpers / 界面辅助

## 中文

本模块保存中英文切换、全屏等独立界面能力。能力不可用时必须安全降级，不得改变玩法状态。

`Neon_Autopilot_V23_HighSpeed_DroneHeat.i18n.js` 是所有玩家可见文案的双语权威，只支持 `zh-CN` 与 `en`，默认使用简体中文。初始语言按“网址中的 `lang` 参数 → `NeonV23Startup.readString()` 保存值 → 简体中文”解析；玩家切换后的选择通过 `NeonV23Startup.writeString()` 保存到 `cc-v23-ui-language`，界面层不得直接访问浏览器存储。

`startup.loading.*` 是唯一初始加载层的双语命名空间，提供“模块 / 世界 / 道路 / 图形 / 首帧”真实阶段，以及 `tipLabel` 和 `tip.steering / view / ramps / candlelight / damage / weather` 六条稳定提示。中英文键必须一一对应，且阶段与提示都不得包含百分比、剩余时间或 ETA。运行时只能在对应工作真实完成时更换阶段，提示也只能随严格前进的真实阶段同步换条；语言切换按当前 tip ID 重绘，不能推进提示、就绪状态或启动。加载外层是非 live 容器，阶段状态是唯一 `aria-live="polite"` 通道；提示使用不可聚焦的 `role="note"` 与 `aria-live="off"`，没有“下一条”等操作。开始页在此期间保持 `hidden + inert`，开始按钮保持原生禁用。普通就绪发布必须先启用开始按钮、再显示开始页、最后关闭加载状态；更新提示和致命恢复可按各自优先级覆盖它，显式 `autostart=1` 则可在玩家确认后直接启航而不短暂显示开始页。

静态界面优先使用 `data-i18n`、`data-i18n-attr` 和专用可访问属性绑定。迁移期间，模块也会翻译已知的普通文本节点以及 `aria-label`、`aria-valuetext`、`title`、`placeholder`，并用弱引用保留原始文案，使中文与英文可以反复无损切换。动态新增或更新的界面由变化观察器仅对受影响子树重新应用；该局部路径不得改写 `document.title`，文档标题与语言元数据只由初始完整应用或显式 `setLanguage()` 切换更新。画布、道路标牌和运行时组合文案必须在绘制或写入时调用 `t()`、`translate()` 或 `translateSource()`，数字使用 `formatNumber()`。

独立出现的物理按键与仪表 token `A–Z`、`SPACE` 属于跨语言硬件标识，`translateSource()` 必须原样返回；这避免 `S`、`M` 被普通文案反向索引误译为“分”“合”。地图“分流/汇流”等真正语义仍必须使用明确的稳定翻译键，不能依赖单字母 token。

`hud.mobile.*` 是移动驾驶舱唯一双语命名空间，覆盖飞行仪表区域名、“仪表/地图”按钮、关键四值与快捷操作组名称、触控驾驶组名称，以及两块详情各自的展开/收起可访问名称。按钮的可见短标签由静态 `data-i18n` 更新；当前折叠方向由运行时按既有状态重新选择 `expandAria / collapseAria` 并同步 `aria-expanded`，语言切换不能触发折叠。速度、得分、烛光和生命的常驻数值叶节点只接收原权威格式化结果，不由词典写值，也不形成第二份玩法状态。

实时 HUD 与触控驾驶的 `34` 个语义按钮（桌面 HUD `14` 个、移动 HUD `12` 个、触控驾驶含移动换挡与变速箱模式 `8` 个）保留可访问名称、`aria-pressed / aria-expanded` 和鼠标/触控/辅助技术 click，但固定使用 `data-flight-deck-control + tabindex="-1"`，不进入飞行时的键盘焦点序列。界面本地化不得删除这两个标记或把 Enter/Space 重新绑定为目标级按钮激活；Canvas 驾驶焦点与启动、暂停、结算及模态键盘边界由运行时统一管理。

电影模式界面以桌面 `#cinematicBtn / #cinematicBtnState` 和移动 `#mobileCinematicBtn / #mobileCinematicBtnState` 为唯一显式入口；桌面键公开 `aria-keyshortcuts="F"`，而 `C` 继续只属于四驾驶视角循环。`cinematic.state.*`、可访问名称、启停状态句与二十五个镜位名构成一一对应的中英文合同。F 入口/退出只保存、恢复视角，不改变 P、M、T、MT/AT 或任何驾驶输入。电影中 P/M/T、挡位和触控驾驶键保持可用；MT 显示 Q/E，AT 隐藏手动换挡键并由自动箱接管。HUD 始终显示真实权威；P 关闭即手动，P 开启才领航。移动入口只位于显示工具抽屉，不占用四枚常驻驾驶键。语言切换只重绘导演状态与镜位名，不能启停导演、改变驾驶权威或写玩法状态。

`autopilot.*` 是自动领航指令 HUD 的显式双语合同，覆盖稳定意图、四级风险、风险百分比 ARIA、横向/纵向权威、手动/弯道/对向边界/障碍制动、最近威胁/TTC、手机权威摘要及离散播报；`autopilot.panelEyebrow` 只命名静态“航迹控制 / Flight director”副标题，不代表第二种领航模式。`autopilot.threat.distanceTtc` 自身拥有中英文秒单位，调用方只能传无单位数值；`autopilot.authoritySummary.valueAria` 提供适合朗读的标点。`#autoIntentText / #autoRiskLabel / #autoRiskText / #autoLateralAuthorityText / #autoLongitudinalAuthorityText / #autoBrakeText / #autoNextObstacleText / #autoRiskMeter / #autoRiskFill / #autoAuthoritySummary` 是非 live 的高频投影；`#autoAuthorityAnnouncement` 是唯一 `role="status" aria-live="polite"` 通道，只接受权威或制动状态真正改变时的完整句子。语言切换只按当前权威状态重绘这些叶节点，不得创造控制权变化、制动事件、威胁或第二份领航状态。

`hud.propulsion.*` 是推进核心标签、零烛光 `1,800–12,000 rpm` 至成长上限渐近 `15,000 rpm` 的可访问转速文案，以及 `idle / creep / spooling / shifting / lugging / stalled / thrust / coast / braking` 九种状态的双语合同。`creep` 明确表示贴地1挡、零踏板时由真实怠速扭矩驱动的低速蠕行；`lugging` 表示 MT 高挡低速的真实拖挡削力，`stalled` 表示更严重的完全失速与零推力，三者都不得伪装成正常踩油门推进。`hud.handling.*` 保留稳定键名，但玩家标签为“成长 / Growth”，说明暖金→紫→青的船色、横向操控、转速上限与升转速度来自同一烛光档案。运行时只从权威推进状态和成长档案写入转速、动态 ARIA 上限、总实际推力、怠速分量、带正负号的净加速度及当前状态；界面不得从按键或速度反推，也不得把逐帧变化放入 `aria-live`。

`hud.speedometer.*`、开始页和手册必须呈现同一真实速度合同：新局从 `0km/h` 静止起步，松开 W 立即切掉踏板额外推力；贴地1挡在干燥平路由怠速扭矩与阻力缓慢平衡于约 `8km/h`，`16km/h` 起蠕行力归零，S 可完全停车，2/3挡、换挡和腾空均无隐藏蠕行。1挡满油门日常干地自然约 `110km/h`，2挡约 `160km/h`，高速道路与跳台3挡约 `280km/h`，行车制动约为 `7.5m/s²`。金色巡航刻度位于表盘 `79%`；更高速度只进入连续压缩显示，不能被描述为默认速度、最低速度或硬上限。

`gear.*` 是桌面 `#gearDownBtn / #gearIndicator / #gearUpBtn / #transmissionModeBtn / #gearOperatingRange` 与移动 `#mobileGearDownBtn / #mobileGearIndicator / #mobileGearUpBtn / #mobileTransmissionModeBtn / #mobileGearOperatingRange` 的唯一双语合同。T 和两枚模式按钮只切换 MT 手动挡 / AT 自动挡；P 关闭时 M 在 W 手动与无目标速度上限的持续满油门之间切换；P 开启时由领航统一调油、滑行和制动，M 只保存退出 P 后的偏好。M 不拥有换挡。MT 的 Q/E 只请求相邻挡位：1挡推荐 `0–90km/h` 且 `≥70` 可升2挡；2挡推荐 `70–140`、`≤125` 可降1挡、`≥140` 可升3挡；3挡是高速道路与跳台推进级，推荐 `140–280`、`≤190` 可降2挡。这些是工作带而非硬限速。MT 高挡低速保留所选挡位：部分负载进入 `lugging`，完全失去传动速度则进入 `stalled`；仪表与中央提示必须给出安全恢复挡和明确的 `Q×N` 次数。AT 覆盖三挡，并把桌面/触控 Q/E 同步设为 `hidden + inert + aria-hidden + disabled`，回收按钮列、焦点和移动空间；当前挡、T、精确自动阈值与三挡工作带必须继续显示。自动箱在 `≥90` 由1挡升2挡、`≤70` 回1挡、`≥140` 由2挡升3挡、`≤120` 回2挡；两组 `20km/h` 滞回避免临界速度反复换挡。P 的 `120km/h` 普通巡航通常保持2挡，P 关闭后的无上限满油门可自动升入3挡。AT 高挡低速仍真实进入 `lugging / stalled`，但文案说明自动箱将按阈值降入安全挡，不要求玩家 Q/E。运行时独占约 `0.30s` 推力中断、RPM 下降与安全降挡判定；状态优先级为 `shifting > rejected > stalled > lugging > engaged`。桌面及 `390×844` 触屏都同时显示 MT/AT、当前挡精确操作提示与三挡工作带；手机 T 控件始终至少 `44px`，Q/E 只在 MT 中保留 `44px` 目标。离散告警可以进入 polite live-region，但逐帧转速、推力或严重度不得刷屏；CSS 只投影权威状态，不从速度自行推断模式、拖挡或资格。

生命卡与烛光成长卡拥有互斥的语义命名空间和不同的非颜色提示。`#lifeMetric` 只接受 `data-life-count`、固定三个 `data-life-slot/data-life-active` 和 `data-life-state="healthy|wounded|critical|depleted"`，其三段完整度轨及移动镜像均为 `aria-hidden` 装饰；`#handlingMetric` 只接受烛光计数、连续 `data-handling-progress` 与 `data-handling-level="base|responsive|agile|elite"`，移动镜像使用同一连续进度。界面绑定不得在两卡之间复制 data 属性，运行时 `updateLifeMeter()` / `updateHandlingMeter()` 与样式 `--life-*` / `--candle-*` 必须保持一一对应且完全隔离。

`hud.damage.*` 是受击反馈、剩余生命和“无敌护盾”可见标签的唯一双语命名空间。`#damageAnnouncement` 是唯一 `aria-live="assertive" aria-atomic="true"` 受击播报区：每次真正接受的普通损伤恰好写入一次完整播报；无敌期或同一渲染帧内被拒绝的接触不得清空、改写或重复播报。常驻生命数值、三颗心与护盾装饰保持非 live；桌面 `#lifeProtectionTime` 的十分之一秒和手机环形进度均位于 `aria-hidden` 保护装饰内，只读同一权威比例。语言切换可重译当前静态标签，但不得合成一次新损伤、重播旧播报或改变 `1.32s` 权威保护计时。

`hud.hoodCollisionGuide.*` 在 `hood-collision-guide-v3` 中只本地化桌面视口下缘的真实宽度读数；移动端隐藏该读数，四个短角标、两条下侧导轨以及常态/琥珀警戒/红色危险都不依赖可见文案。覆盖层保持 `aria-hidden`、无 `role`、无 `tabindex` 且不接收指针。语言切换只能重写当前桌面读数，不得重算由真实伤害 `colliderHalf`、已提交 `PathPlan` 和只读有界探针决定的投影或 TTC 状态；它不拥有未来跳台 lip/活动腾空、地面/顶棚预测，不得发起物理扫掠、解除无效状态的 `hidden`，也不能写路线、跳跃、碰撞、玩法或物理。

所有 `[data-language-toggle]` 按钮共用同一语言状态；带 `[data-language-compact]` 的窄按钮在中文界面显示“英”，在英文界面显示“ZH”，同时同步可访问名称。`setLanguage()` 先完成文档、静态节点和按钮更新，再通知 `subscribe()` 订阅者并派发 `neonv23:languagechange`，让动态界面和画布按现有状态重绘。

`launch.restartConfirm.*` 与 `guide.feature.pauseRestart.*` 是暂停重开二级确认及其手册说明的双语权威。确认层打开时切换语言只刷新文本、文档语言和可访问名称，不得关闭弹层、恢复游戏或改变本局状态。

`guide.feature.launchAndRamps.*` 明确区分主动起飞和随机实体跳台：SPACE/触控可从平路、结构纵坡与跳台承载面主动起飞，坡上保留切向垂直速度并叠加投影后的主动冲量。主动飞行仍受当前路线护栏约束，不获得平台跨车道权限；领航仍禁止在坡面叠加 SPACE。若不主动起飞，飞船仍需进入3挡并把进台速度建立到约 `260km/h`：MT 用 E 手动升挡，AT 在无上限满油门加速到 `140km/h` 时自动升入3挡。跳台坡唇自然离地不能点亮 SPACE 或使用“跳跃”可访问名称。只有这种坡唇腾空的落点安全范围允许到道路中心左右各约 `42m`，但空中转向仍在 `10m/s` 横移速度和 `17m/s²` 横向加速度达到饱和；四种跳台已验证可在约 `260km/h` 时跨越约 `24m` 道路间距，不得暗示隐藏横向助推。手册同时把道路外落地标为立即坠毁。`launch.offRoadCrashStatus` 使用同一实际腾空时间、最终得分和最高分，在结束页与语言切换重放中保持一致。

`guide.view.* / guide.context.* / guide.quickstart.* / guide.authority.* / guide.footer.*` 是 v18 手册渐进披露、只读当前航程、60 秒快速上手、P/M 权威矩阵和章间导航的双语命名空间。初始 Essential/“必会”显示 `16` 项，Complete/“完整”显示同一玩家账本的全部 `43` 项。当前航程快照同时描述 P/M 决定的真实驾驶权威和独立电影镜头状态；F 不覆盖横向或纵向权威。P 关闭时 M 决定 W 手动或持续满油门，P 开启时领航拥有纵向权威。字符串只格式化打开时冻结的快照，不能创建逐帧通道或改变状态。语言切换可重绘范围、上下文、章名、进度和可访问名称，但不得切换功能、章节或焦点。

翻译只能写纯文本与属性，不得使用 `innerHTML`，也不得写入速度、路线、碰撞、生命或其他玩法状态。

全屏模块统一绑定开始页右上工具键与 HUD 全屏键；两者共享 `document` 的同一整页全屏状态，并只更新各自的状态子节点、视觉状态、`aria-pressed` 与可访问名称，保持既有图标、标签及按钮结构。最小宿主夹具没有状态子节点时才回退为整段按钮文字。只有玩家主动点击任一控件才会请求进入或退出全屏；初始化、语言更新、`sync()` 和 `fullscreenchange` 都不得自动请求。该能力独立于启动 action，不读取、取得或推进 `ready / committing / commit`，也不改变玩法状态。浏览器通过 `Esc` 或浏览器界面退出时，两枚控件必须同步更新。

## English

This module owns isolated UI capabilities such as Chinese/English switching and fullscreen. Unsupported capabilities must degrade safely without changing gameplay state.

`Neon_Autopilot_V23_HighSpeed_DroneHeat.i18n.js` is the bilingual authority for all player-facing copy. It supports only `zh-CN` and `en`, with Simplified Chinese as the default. Initial language resolves in this order: the URL `lang` parameter, the value returned by `NeonV23Startup.readString()`, then Simplified Chinese. Player choices are saved as `cc-v23-ui-language` through `NeonV23Startup.writeString()`; the UI layer must not access browser storage directly.

`startup.loading.*` is the sole bilingual namespace for the initial loading surface. It provides the real Modules / World / Routes / Graphics / First frame stages plus `tipLabel` and the six stable `tip.steering / view / ramps / candlelight / damage / weather` entries. Chinese and English keys remain one-to-one, and neither stages nor tips may contain a percentage, remaining-time estimate, or ETA. Runtime may change stage only when that work actually completes, while a tip may change only with strict real-stage progress. Language changes redraw the current tip ID without advancing tips, readiness, or launch. The loader shell is non-live, the stage status is the sole `aria-live="polite"` channel, and the unfocusable tip uses `role="note"` with `aria-live="off"` and no Next control. While loading is active, the launch surface stays `hidden + inert` and Start stays natively disabled. Normal readiness enables Start first, reveals launch second, and closes the loading state last. Update notice and fatal recovery may supersede it according to their priorities, while explicit `autostart=1` may launch directly after confirmation without flashing Start.

Static UI should use `data-i18n`, `data-i18n-attr`, and the dedicated accessible-attribute bindings. During migration, the module also translates known ordinary text nodes and `aria-label`, `aria-valuetext`, `title`, and `placeholder` values. Weak references preserve their authored sources so repeated Chinese/English switches are lossless. A mutation observer reapplies localization only to affected subtrees; that local path must not rewrite `document.title`, which changes with language metadata only during the initial full apply or an explicit `setLanguage()` switch. Canvas labels, road signs, and runtime-composed copy must call `t()`, `translate()`, or `translateSource()` when rendered or assigned, and player-facing numbers use `formatNumber()`.

Standalone physical-key and instrument tokens `A–Z` and `SPACE` are language-neutral hardware labels, so `translateSource()` must return them unchanged. This prevents `S` and `M` from colliding with reverse-indexed copy such as Chinese split/merge labels. Real map semantics such as split and merge must continue to use explicit stable translation keys rather than single-letter tokens.

`hud.mobile.*` is the sole bilingual namespace for the mobile cockpit. It owns the flight-instrument region name, compact Gauges/Map labels, the critical-glance and quick-action group names, the touch-driving group name, and each detail surface's Expand/Collapse accessible name. Static `data-i18n` updates visible short labels; runtime reselects `expandAria / collapseAria` from the existing fold state and synchronizes `aria-expanded`, so a language change cannot toggle either surface. Persistent speed, score, candlelight, and lives value leaves receive only the original authoritative formatted values; the catalog neither writes those values nor creates a second gameplay state.

The `34` semantic live-deck controls (`14` desktop HUD, `12` mobile HUD, and `8` touch-driving controls including mobile shifting and transmission mode) retain accessible names, `aria-pressed / aria-expanded`, and mouse, touch, or assistive clicks, but remain outside the in-flight keyboard sequence through `data-flight-deck-control + tabindex="-1"`. Localization must not remove either marker or rebind Enter/Space as target-level button activation. Runtime alone owns the Canvas driving focus and the separate launch, pause, debrief, and modal keyboard boundaries.

Film mode has exactly two explicit UI entries: desktop `#cinematicBtn / #cinematicBtnState` and mobile `#mobileCinematicBtn / #mobileCinematicBtnState`. The desktop button exposes `aria-keyshortcuts="F"`, while `C` remains the four-driving-view cycle. Film state, accessible names, status sentences, and twenty-five shot-name keys form one bilingual contract. F entry/exit saves and restores only the view and never changes P, M, T, MT/AT, or driving input. P/M/T, shifting, and touch driving controls remain operable during Film: MT exposes Q/E, while AT hides the manual shift controls and retains automatic authority. The HUD continues to report the true authority: P off is manual and P on is Autopilot. The mobile entry stays in the display-utility drawer and does not displace the four persistent driving controls. Language switching redraws only director state and shot names.

`autopilot.*` is the explicit bilingual contract for the autopilot command HUD.
