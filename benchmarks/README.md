# Benchmarks / 性能观测

## 中文

本目录保存真实 wall-clock 道路与地图观测。它们没有性能失败阈值，不参与确定性门禁，只由统一工具做语法检查。

- `node benchmarks/Neon_Autopilot_V23_HighSpeed_DroneHeat.track.benchmark.mjs`
- `node benchmarks/Neon_Autopilot_V23_HighSpeed_DroneHeat.cloverleaf-map.benchmark.mjs`

## English
