- `lighting.js` 是唯一全局灯光权威：锁定 Three r160 的 sRGB、ACES、非 legacy 物理灯光与浮点 HDR 环境反射；环境光、太阳、月亮、确定性雷电和六盏复用聚光共十盏真实场景灯，其中距离最近的两盏局部灯投影。太阳始终是露天场景的主要光源，开放道路不创建跟随玩家且没有灯具的导航点光。普通桥下的天空/HDR 能量与露天一致，由桥面真实投影自然遮光；桥底灯要同时满足 `underpassBlend > 0.68` 与弱太阳条件才用 `smootherstep` 渐亮，局部灯在路面的估算合计照度不超过太阳的 `32%`，晴朗白天保持关闭。只有 `covered` 或明确 `tunnelKind` 的路线进入深隧道衰减。山体廊道与地下隧道分别按最大 `28m / 22m` 间距沿完整路线密排灯罩和扩散片，整段每一个灯具外观始终可见发亮；仅灯罩与扩散片使用可见自发光，结构壳、侧墙和道路保持非自发光。每个灯具发布带 edge/profile 身份的冻结 authored emitter 位置、方向、强度与射程；六盏复用聚光只绑定 edge 与 profile 同时匹配的记录，找不到精确匹配时保持关闭，绝不生成跟随飞船的路线相对兜底灯。相机前向路线在接近洞门时预备匹配 emitter；只有洞外观察的照明交接随洞门距离渐入，不改变隧道内全部灯具的固定常亮状态。洞门处的 HDR/环境光、天体直射与曝光按 `underpassBlend` 连续衰减，局部聚光在真实灯具下形成有限光池并投下阴影。远处、相邻路线或错误 profile 的灯具不能串光。低/中/高主太阳阴影请求分别为 `1,024 / 2,048 / 8,192`，次级方向光为 `1,024 / 2,048 / 4,096`，局部阴影为 `512 / 1,024 / 4,096`；实际尺寸按 `renderer.capabilities.maxTextureSize` 安全回退。该模块不接收或写入玩法权威。
